# 🗄️ Database Viewer (view-db)

Тестовая программа для просмотра и управления данными базы данных.

## Возможности

- ✅ Выбор типа БД (локальная/рабочая)
- ✅ Просмотр списка всех таблиц
- ✅ Просмотр данных таблицы с пагинацией
- ✅ CRUD операции (Create, Read, Update, Delete)
- ✅ Редактирование записей прямо в таблице
- ✅ Создание новых записей

## Использование

1. Запустите приложение:
   ```bash
   npm run dev
   ```

2. Откройте в браузере:
   ```
   http://localhost:3000/view-db
   ```

3. Выберите тип базы данных:
   - **Локальная БД** - использует `DATABASE_URL` из `.env`
   - **Рабочая БД** - можно настроить отдельную переменную окружения (в будущем)

4. Выберите таблицу из списка и нажмите "Открыть"

5. В таблице доступны:
   - Просмотр всех записей с пагинацией (10 записей на страницу)
   - Редактирование записей (кнопка ✏️)
   - Удаление записей (кнопка 🗑️)
   - Создание новых записей (кнопка "+ Создать")

## Доступные таблицы

- `users` - Пользователи
- `notes` - Заметки
- `categories` - Категории
- `prompts` - Промты
- `tags` - Метки
- `votes` - Голоса

## API Endpoints

- `GET /api/view-db/tables` - получить список таблиц
- `GET /api/view-db/[table]?page=1` - получить данные таблицы с пагинацией
- `POST /api/view-db/[table]` - создать новую запись
- `PUT /api/view-db/[table]` - обновить запись
- `DELETE /api/view-db/[table]?id=xxx` - удалить запись

## Примечания

- Пагинация: 10 записей на страницу
- При редактировании автоматически исключаются поля `id` и поля с датами (`*At`)
- При создании также исключаются эти поля
- Все операции выполняются через Prisma ORM
