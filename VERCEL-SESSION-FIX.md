# Исправление проблемы с сессией на Vercel

## Проблема: Редирект на логин после выбора аккаунта Google

После успешного входа через Google происходит редирект обратно на страницу логина вместо dashboard.

## Возможные причины:

1. **Таблицы не созданы в БД**
   - Таблицы `sessions`, `accounts`, `users` должны существовать
   - Выполните: `npx prisma db push`

2. **AUTH_SECRET не установлен в Vercel**
   - Проверьте переменные окружения в Vercel
   - `AUTH_SECRET` должен быть установлен

3. **Сессия не успевает сохраниться**
   - После callback от Google может потребоваться время
   - Middleware проверяет сессию до её сохранения

4. **Проблема с cookies на Vercel**
   - Cookies могут не устанавливаться из-за настроек домена
   - Проверьте, что используется `https://`

## Что я исправил:

1. ✅ Добавлено логирование в middleware и auth callbacks
2. ✅ Улучшена обработка callback URL
3. ✅ Добавлен redirect callback для правильных редиректов
4. ✅ Включен debug режим для отладки на Vercel

## Что нужно проверить:

### 1. Проверьте таблицы в БД

Убедитесь, что таблицы созданы:
- `users`
- `accounts`
- `sessions`
- `verification_tokens`

Если нет, выполните локально:
```bash
npx prisma db push
```

### 2. Проверьте переменные окружения в Vercel

В Vercel Dashboard → Settings → Environment Variables:

```
AUTH_SECRET=ваш-секретный-ключ
GOOGLE_CLIENT_ID=ваш-client-id
GOOGLE_CLIENT_SECRET=ваш-client-secret
DATABASE_URL=ваша-строка-подключения
```

**ВАЖНО:** `AUTH_SECRET` должен быть установлен!

### 3. Проверьте логи в Vercel

После деплоя проверьте логи:
1. Vercel Dashboard → Deployments → ваш деплой
2. Откройте "Functions" или "Logs"
3. Ищите логи:
   - `[Middleware]` - показывает, видит ли middleware сессию
   - `[Auth] Session callback` - показывает данные сессии
   - `[Auth] SignIn callback` - показывает данные при входе
   - `[Auth] Redirect callback` - показывает редиректы

### 4. Проверьте cookies в браузере

1. Откройте DevTools (F12)
2. Application → Cookies
3. Проверьте, что есть cookie с именем `authjs.session-token` или похожим
4. Если нет - сессия не устанавливается

## Отладка:

После деплоя с новыми изменениями:

1. Попробуйте войти через Google
2. Проверьте логи в Vercel Dashboard
3. Проверьте cookies в браузере
4. Если сессия не создается, проверьте:
   - Таблицы в БД
   - Переменные окружения
   - Логи на ошибки подключения к БД

## Если проблема сохраняется:

1. Проверьте логи в Vercel - там будет видно, что происходит
2. Убедитесь, что `AUTH_SECRET` установлен и правильный
3. Проверьте, что таблицы `sessions` созданы в БД
4. Попробуйте очистить cookies и войти снова
